# PupCut

Field takeoff calculator for pipe pups.

Pick the fitting on each end, enter the overall center-to-center length, and get the pup (cut) length:

`Pup = overall − takeoff A − takeoff B − (root gap × welds)`

Includes ASME B16.9 butt-weld takeouts and common threaded fitting allowances. Always verify on the job before cutting.
