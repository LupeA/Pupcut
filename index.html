How pup takeoff works

Measure overall center-to-center (or face-to-face if that is how you laid it out). Subtract each fitting’s takeoff, then subtract root gaps for butt-welds.

Pup = overall − takeoffA − takeoffB − (gap × welds)

Butt-weld values follow ASME B16.9 center-to-end charts. Threaded values use common Class 3000 fitting allowances (center-to-end minus engagement). Always verify on the job — makers can differ slightly.
